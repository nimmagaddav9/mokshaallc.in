•	Design robust loading, validation, empty, error, and degraded-state experiences.

•	Collaborate with the iOS engineer on shared API contracts, design patterns, navigation, and journey behavior.
•	Own accessibility, product analytics, frontend telemetry, performance, and automated UI testing.
